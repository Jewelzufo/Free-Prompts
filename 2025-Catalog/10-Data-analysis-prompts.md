# Advanced Prompt Engineering for Complex Data Analysis Tasks

## Prompt Templates with Tool Integration:

Here is a collection of ten diverse prompt templates, including the previous five, designed to inspire innovative applications of prompt engineering for various data-centric use cases:

1. **Customer Behavior Analysis**:
   ```
   Analyze the customer journey and behavior patterns for <company_website>:
   1. Track user navigation paths and identify popular content sections. [Use website analytics data and process page views]
   2. Calculate the average time spent on different product pages. [Analyze user session data]
   3. Visualize user engagement trends over the past year. [Canvas: Create a line chart for engagement metrics]
   
   Tools:
   - Website Analytics: Process page views and user sessions data.
   - Canvas: Plot user engagement trends over time.
   ```

2. **Social Media Trend Analysis**:
   ```
   Uncover the latest trends and influencers in the <industry_topic> niche on social media:
   1. Identify the top 10 trending hashtags and topics. [Search and analyze recent social media posts]
   2. Discover influential accounts and their engagement metrics. [Find and list top influencers]
   3. Visualize sentiment towards new product launches. [Use canvas for sentiment visualization]
   
   Tools:
   - Search: Explore and filter social media content.
   - Canvas: Visualize sentiment analysis results.
   ```

3. **Healthcare Data Insights**:
   ```
   Provide critical insights from patient records for <medical_specialty> department:
   1. Identify patients at high risk for readmission. [Apply predictive modeling on historical data]
   2. Analyze treatment effectiveness using patient feedback. [Process patient testimonials with NLP]
   3. Visualize patient recovery trends. [Canvas: Plot recovery timelines]
   
   Tools:
   - Predictive Modeling: Predict high-risk patients.
   - Natural Language Processing: Analyze patient feedback.
   - Canvas: Visualize patient recovery journeys.
   ```

4. **E-commerce Personalization**:
   ```
   Enhance the personalization strategy for an e-commerce platform:
   1. Recommend products based on user purchase history. [Implement collaborative filtering on transaction data]
   2. Create personalized email campaign content. [Use NLP to analyze past campaign success]
   3. A/B test different homepage layouts for user segments. [Search for A/B test results and analyze conversion rates]
   
   Tools:
   - Collaborative Filtering: Generate personalized product recommendations.
   - Natural Language Processing: Process email campaign content.
   - A/B Testing: Analyze conversion rates for website variations.
   ```

5. **Fraud Detection in Banking**:
   ```
   Develop a fraud detection system for <bank_name>:
   1. Identify suspicious transaction patterns. [Apply anomaly detection on transaction data]
   2. Analyze customer behavior associated with fraudulent activity. [Search for and profile fraudulent accounts]
   3. Visualize fraud trends over time. [Canvas: Plot fraud case timelines]
   
   Tools:
   - Anomaly Detection: Detect unusual transaction patterns.
   - Search: Investigate and profile fraudulent accounts.
   - Canvas: Visualize fraud trends and patterns.
   ```

6. **Multi-Step Data Exploration with Search and Visualization** (from previous list):
   ```
   Explore the dataset titled <dataset_name> to uncover insights:
   1. Identify key factors affecting <target_variable>. [Search and apply statistical analysis]
   2. Visualize historical trends of <metric_to_plot>. [Use canvas for time-series visualization]
   3. Compare <comparison_criteria> across different segments. [Search and visualize comparisons]
   
   Tools:
   - Search: Explore and filter relevant data.
   - Canvas: Generate interactive visualizations.
   - Statistical Analysis: Calculate correlations or perform other statistical tasks.
   ```

7. **Financial Analysis with Coding and Visualization**:
   ```
   Conduct a financial analysis for <company> using their annual reports:
   1. Calculate financial ratios: Current Ratio, ROE, and Debt-to-Equity. [Write and execute financial formulas]
   2. Visualize stock performance against industry peers. [Fetch and plot stock data using canvas]
   3. Predict Q4 revenue based on historical trends. [Utilize time series forecasting]
   
   Tools:
   - Code Interpreter: Implement financial calculations and forecasting models.
   - Canvas: Visualize stock performance and forecasts.
   ```

8. **Sentiment Analysis for Product Reviews**:
   ```
   Analyze customer feedback for <product_launch> launch:
   1. Determine overall sentiment towards the new features. [Apply sentiment analysis on reviews]
   2. Extract common pain points and suggestions. [Use NLP for topic modeling]
   3. Visualize sentiment changes over product iterations. [Canvas: Create a sentiment timeline]
   
   Tools:
   - Natural Language Processing: Process reviews for sentiment and themes.
   - Canvas: Visualize sentiment journey.
   ```

9. **Geospatial Market Analysis**:
   ```
   Study the market for <industry> using geospatial data:
   1. Pinpoint high-potential markets for expansion. [Analyze sales data by region]
   2. Map out store locations and competitors. [Use canvas for interactive mapping]
   3. Identify optimal locations for pop-up stores. [Apply clustering on demographic data]
   
   Tools:
   - Search: Explore sales and demographic data by region.
   - Canvas: Create interactive maps.
   - Clustering: Uncover market clusters.
   ```

10. **Time Series Forecasting**:
    ```
    Forecast <metric_to_predict> for the upcoming quarter:
    1. Preprocess historical data and handle outliers. [Clean and prepare time series data]
    2. Build a forecasting model using Prophet. [Code interpreter for model training]
    3. Visualize predicted trends with confidence bands. [Canvas for forecasting visualization]
    
    Tools:
    - Code Interpreter: Implement data preprocessing and forecasting models.
    - Canvas: Plot forecasts with uncertainty ranges.
    ```

These prompts showcase the versatility of prompt engineering, offering a creative blend of instructions, placeholders, and tool usage, enabling Large Language Models to assist in a wide array of data-intensive tasks.
