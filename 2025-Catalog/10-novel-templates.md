1. The Constraint‑Driven Innovator

```
You are an expert in {domain}. Generate {number} innovative solutions for {goal} under these constraints: {constraint_1}, {constraint_2}, ….

For each solution, provide:
1. A brief rationale  
2. A next‑step action plan
```

---

2. The Reverse‑Engineering Detective

```
I have an outcome: {desired_outcome}. Break it down into its implicit assumptions, necessary resources, and sequential steps to reproduce it.

Present your findings as a numbered investigation report:
1. Assumptions  
2. Resources  
3. Steps
```

---

3. The Role‑Swapping Mentor

```
Assume the role of {role_A} teaching {role_B} how to accomplish {task}.

1. Outline the core principles in simple terms  
2. Provide an illustrative example tailored to {context_or_audience}
```

4. The Multi‑Perspective Analyzer

```
Analyze {topic} from the perspectives of {stakeholder_1}, {stakeholder_2}, and {stakeholder_3}.

For each perspective, list:
- Top 3 concerns  
- Top 3 opportunities  
- Top 3 recommended actions  

Conclude with a synthesis of conflicts and synergies.
```

---

5. The Constraint‑Relaxation Innovator

```
Take the problem: {problem_statement}.

Now imagine each of these constraints removed one at a time: {constraint_1}, {constraint_2}, ….

For each relaxed scenario:
1. Describe how the solution space changes  
2. Suggest the most promising new approach
```

6. The Narrative Roadmap

```
Craft a step‑by‑step journey narrative for a character named {protagonist} embarking on {challenge}.

Include {number_of_stages} stages, each with:
- A mini cliffhanger  
- A lesson learned  
- A call‑to‑action for the reader
```

7. The Data‑Driven Hypothesizer

```
Given the dataset description: {data_summary}, propose {number} testable hypotheses.

For each hypothesis:
1. Define necessary variables  
2. Suggest an analytic method  
3. Predict possible outcomes with rationale
```

8. The Creative Constraint Combiner

```
Combine constraints {constraint_A} and {constraint_B} in a creative challenge to generate {number} novel ideas for {project_or_product}.

For each idea, specify how it leverages both constraints to deliver unique value.

```
Guide me through understanding {complex_concept} by asking Socratic questions.

After each question:

Progress toward a full explanation of {learning_objective}.
```

```
