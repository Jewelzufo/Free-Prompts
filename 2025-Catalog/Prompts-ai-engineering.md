# Prompt Templates for AI Engineers

<br>

**Counterfactual Scenario Generation**:

```
"Generate a scenario where {EVENT} did not occur, and describe the consequences of this alternative history. The scenario should be {LENGTH} words and include {NUMBER} key events."
```

**Multimodal Storytelling**:

```
"Create a story that combines {TEXT}, {IMAGE}, and {AUDIO} elements to tell a narrative about {CHARACTER} and their journey to {GOAL}. The story should be {LENGTH} words and have a {TONE} tone."
```

**Explainable AI Model Interpretation**:

```
"Interpret the output of a {MODEL TYPE} model on a {DATASET} and explain the results in {LENGTH} sentences. The explanation should include {NUMBER} key insights and be written in a {TONE} tone."
```

**Conversational Role-Playing**:

```
"Engage in a conversation with a user playing the role of {CHARACTER} in a {SETTING}. The conversation should last for {LENGTH} turns and include {NUMBER} plot twists."
```

**Data-Driven Poetry Generation**:

```
"Generate a poem based on the data {DATA} and written in the style of {POET}. The poem should be {LENGTH} lines and include {NUMBER} metaphors."
```

**Personalized Recommendation System**:

```
"Recommend {NUMBER} products to a user with {PREFERENCES} and {INTERESTS}. The recommendations should be based on {ALGORITHM} and include a brief description of each product."
```

**Text-Based Adventure Game**:

```
"Create a text-based adventure game where the player is {CHARACTER} and must navigate through {WORLD} to reach {GOAL}. The game should include {NUMBER} challenges and have a {TONE} tone."
```

**Summarization with Emotional Analysis**:

```
"Summarize the text {TEXT} and analyze the emotions expressed in the text. The summary should be {LENGTH} sentences and include {NUMBER} emotional insights."
```

**Dialogue-Based Sentiment Analysis**:

```
"Analyze the sentiment of a conversation between {CHARACTER1} and {CHARACTER2} about {TOPIC}. The analysis should be {LENGTH} sentences and include {NUMBER} key points."
```

**Generative Art Description**:

```
"Generate a description of a {ART STYLE} artwork that depicts {SCENE}. The description should be {LENGTH} words and include {NUMBER} artistic insights."
```

**Question Answering with Commonsense Reasoning**:

```
"Answer the question {QUESTION} using commonsense reasoning and provide {NUMBER} supporting examples. The answer should be {LENGTH} sentences and have a {TONE} tone."
```

**Story Generation with Moral Lessons**:

```
"Generate a {LENGTH}-word story that teaches the moral lesson {LESSON}. The story should include {NUMBER} characters and have a {TONE} tone."
```

**Debate Generation**:

```
"Generate a debate between {ARGUMENT1} and {ARGUMENT2} on the topic {TOPIC}. The debate should be {LENGTH} words and include {NUMBER} key points."
```

**Personalized Language Learning**:

```
"Create a language lesson for a user with {LANGUAGE LEVEL} and {INTERESTS}. The lesson should include {NUMBER} exercises and have a {TONE} tone."
```

**Emotional Support Chatbot**:

```
"Engage in a conversation with a user who is feeling {EMOTION} and provide emotional support. The conversation should last for {LENGTH} turns and include {NUMBER} empathetic responses."
```

**Text-Based Puzzle Generation**:

```
"Generate a text-based puzzle that requires the player to solve {NUMBER} challenges to reach {GOAL}. The puzzle should be {LENGTH} words and have a {TONE} tone."
```

**News Article Generation**:

```
"Generate a news article about {EVENT} in the style of {NEWS SOURCE}. The article should be {LENGTH} words and include {NUMBER} key points."
```

**Social Media Post Generation**:

```
"Generate a social media post for a user with {PERSONALITY} and {INTERESTS}. The post should be {LENGTH} words and include {NUMBER} hashtags."
```

 **Creative Writing with Constraints**:

```
"Write a {LENGTH}-word story that includes the words {WORD1}, {WORD2}, and {WORD3} and is written in the style of {AUTHOR}. The story should have a {TONE} tone and include {NUMBER} plot twists."
```

**Dialogue-Based Game Generation**:

```
"Generate a dialogue-based game where the player is {CHARACTER} and must navigate through {WORLD} to reach {GOAL}. The game should include {NUMBER} challenges and have a {TONE} tone."
```
