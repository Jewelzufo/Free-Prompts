## 🤝 Contributing

We welcome contributions from the community! Here's how you can help:

### 📝 Contribution Guidelines

1. **Template Quality**: Ensure prompts are tested and production-ready
2. **Documentation**: Include clear usage examples and expected outcomes
3. **Organization**: Follow our categorization structure
4. **Attribution**: Maintain proper attribution for original work

### 🚀 How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/new-prompts`)
3. Add your templates following our [Style Guide](./CONTRIBUTING.md#style-guide)
4. Submit a pull request with detailed description

[Read Full Contributing Guidelines](./CONTRIBUTING.md)
