**About:**
> *This repo contains a curated collection of high-quality, production-ready prompt templates for AI engineers, analysts, and enterprise teams*

## How to use

Pick a prompt from the table below, open the file, and copy the prompt text. Every prompt file carries frontmatter with its title, category, model, use case, and update date, so you can tell at a glance what it is for. [CATALOG.md](CATALOG.md) lists every file in one flat table for find-in-page search.

## Contents

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md). New prompts go in the matching category folder, in lowercase kebab-case `.md`, with frontmatter, and listed in [CATALOG.md](CATALOG.md) and the category README.
